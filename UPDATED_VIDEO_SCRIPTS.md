# Panta Video Scripts — Complete Set (v2)

Seven production-ready scripts organized into two groups: the **Mission Trilogy** (who / why / how) and the **Funnel Set** (opportunity, diagnosis, framework, distillation). Each script owns distinct language so no two videos sound alike in sequence.

**General delivery notes:**
- Conversational pace, ~140 words/minute. Pauses marked with (beat).
- On-screen text (OST) reinforces key phrases — never duplicates full sentences.
- Shoot all direct-to-camera segments in one session for consistent wardrobe/lighting. DBI and AHT projects are the b-roll library.
- Every script funnels to one destination: the free consultation at panta.llc.

---

**(beat)**

*OST: "Understand what's possible. Execute within your means."*

# SHARED LANGUAGE MAP

Each video owns its signature language. In editing and sequencing, avoid pairing videos that lean on the same word in their opening lines.

| Word / phrase | Owner | Also appears in (keep secondary) |
|---|---|---|
| "Two worlds" / founder story | Script 1 | — |
| "Resources" (as thesis) | Script 1 | 2, 3, 7 — unavoidable; it's the brand thesis. Never in two adjacent openings. |
| "What's possible" | Script 4 | 1, 2 — Script 4 owns it as the hook; elsewhere it's supporting language |
| "My fear" / "the gap" | Script 2 | — |
| "So you don't have to" | Script 2 | 4 ("staying ahead... so you don't have to") — acceptable echo, different framing |
| "Researchers, engineers, designers, creative thinkers" | Script 3 | — (the identity line; use in site copy too) |
| "Leaks" | Script 5 | 6 — Script 6 references leaks in passing; Script 5 owns the metaphor |
| "Find. Trust. Choose." | Script 6 | — (candidate for site nav / consultation framing) |
| "Uncommon ways" | Script 7 | — |
| "2026" | Script 4 | — (will need annual refresh) |

**Sequencing rules:**
- Autoplay pairs to avoid: 1→2 (both open on scale-of-change/resources framing), 4→2 (both lean "possible"/"pace of change")
- Safe autoplay sequences: 1→3, 5→6, 7→1, 4→5
- The trilogy (1→2→3) works as a sequence *because* each hands off to the next ("that partner" in 2 is answered by 3's opening question) — just don't autoplay it with Script 4 appended.

# PRODUCTION NOTES

- **Visual system:** Cream backgrounds, charcoal text, bamboo green accents for OST highlights. Spectral for headline OST, Instrument Sans for supporting text — consistent with the site.
- **Wardrobe/lighting:** One session for all seven direct-to-camera segments; b-roll gathered separately.
- **CTA consistency:** One destination (panta.llc), one action (free consultation / assessment booking). Script 5 says "assessment," all others say "consultation" — confirm these route to the same booking page or align the language.
- **Annual refresh flag:** Script 4's "2026" hook needs updating each January, or soften to "right now" for an evergreen cut.
